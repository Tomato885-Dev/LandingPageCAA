# Carpeta de logos

Guarda aquí los logos de los colaboradores.

- Formato recomendado: `.png` o `.svg` con **fondo transparente**.
- Como el sitio tiene fondo negro, usa logos en versión **blanca o clara**.
- Alto sugerido: 200 px (el ancho se ajusta solo).

Para usarlo, escribe la ruta en `src/contenido/colaboradores.js`:

    { nombre: 'Nombre de la organización', logo: 'assets/logos/nombre.png', url: 'https://...', tipo: 'Institución' },
